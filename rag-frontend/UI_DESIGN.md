# 智能问答系统 - 前端界面

## 界面设计概述

本系统采用符合大厂标准的专业智能体问答系统界面设计，提供流畅的用户体验和现代化的视觉风格。

## 布局结构

### 三区域划分设计

```
┌─────────────────────────────────────────────────────────┐
│  侧边栏 (Sidebar)      │  主问答区域 (ChatArea)    │
│                        │                          │
│  - 历史对话列表        │  - 对话消息流            │
│  - 新建对话按钮        │  - 输入框               │
│  - 可调整宽度          │  - 学科筛选             │
│  - 可折叠              │                          │
│                        │                          │
│  [拖拽调整宽度]        │                          │
└─────────────────────────────────────────────────────────┘
```

### 顶部区域

- 保持空白，不添加任何功能元素
- 为未来扩展预留空间

## 核心功能特性

### 侧边栏功能

1. **可调整宽度**
   - 支持拖拽调整宽度（200px - 500px）
   - 平滑的拖拽体验
   - 实时预览宽度变化

2. **可折叠状态**
   - 一键收起/展开侧边栏
   - 状态保存在 localStorage
   - 用户会话期间保持记忆

3. **历史对话列表**
   - 显示对话标题（基于 session_id）
   - 显示时间戳（智能格式化）
   - 支持删除对话
   - 当前对话高亮显示

4. **新建对话**
   - 醒目的新建对话按钮
   - 渐变色设计，易于识别
   - 悬停动效反馈

### 主问答区域功能

1. **对话消息流**
   - 清晰的消息展示
   - 用户/AI 消息区分
   - 头像标识
   - 流式输出支持

2. **输入区域**
   - 大尺寸输入框
   - 支持 Enter 发送
   - 支持 Shift+Enter 换行
   - 学科筛选下拉框
   - 发送按钮状态反馈

3. **欢迎界面**
   - 空状态时显示欢迎信息
   - 功能特性展示
   - 动画效果

## 响应式断点

- **桌面端**：> 768px
  - 侧边栏可调整宽度
  - 完整功能展示

- **移动端**：≤ 768px
  - 侧边栏固定定位
  - 收起时隐藏
  - 输入框自适应

## 使用说明

### 启动应用

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 功能操作

1. **新建对话**
   - 点击侧边栏"新建对话"按钮
   - 或点击输入框左侧的"+"按钮

2. **调整侧边栏宽度**
   - 鼠标拖拽侧边栏右边缘
   - 宽度范围：200px - 500px

3. **折叠/展开侧边栏**
   - 点击侧边栏右上角的箭头按钮
   - 状态自动保存

4. **选择历史对话**
   - 点击侧边栏中的对话项
   - 对话内容自动加载

5. **删除对话**
   - 悬停在对话项上
   - 点击删除按钮（✕）

6. **发送消息**
   - 输入问题后按 Enter
   - 或点击发送按钮
   - Shift+Enter 换行

7. **筛选学科**
   - 选择输入框右侧的学科下拉框
   - 支持全部、人工智能、Java
