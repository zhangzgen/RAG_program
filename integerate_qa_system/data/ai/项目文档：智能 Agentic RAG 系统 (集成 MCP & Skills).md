# 项目文档：智能 Agentic RAG 系统 (集成 MCP & Skills)

一个集成skill 和 MCP 的 agentic RAG系统,用于企业内部管理内部知识, 系统支持Agent动态决策是否检索向量数据库以及调用skill 和 mcp, 包含数据闭环 -> 即用户能够对agent输出进行赞和踩的标记, 所有标记数据会被存储为QA对,并保留agent的决策过程,以及向量的检索结果.用于后续的BadCase的分析以及GoodCase的使用.

## 前端描述

- 采用react框架

- 风格: 简约现代

- 登录方式: 采用邮箱接收验证码的方式注册和登录

- 页面说明:

  - 聊天界面: 1.左边侧栏管理历史对话,2. 中间部分进行对话, 支持文件和图片的传输, 支持流式输出(展示模型思考执行过程和输出结果) 3. 顶部按钮点击能够切换成专业界面(只有管理员采用访问), 
  - 专业界面: 1.包含后端配置文件内容的修改, 2.BadCase 和 GoodCase的管理(支持对每个BadCase标记真实答案) 以及下载为json格式文件, 3.以及向量数据库文件的上传(提交给后端切片存储)和 以及向量数据的检索和溯源(根据当前chunk, 以原始文件格式展示该chunk所在原文的一页内容) 4. 支持上传json格式文件 并进行系统自动评估(后端使用ragas进行评估), 支持skill和mcp的管理
  - 专业界面侧栏进行各个专业功能的切换
  - 向量数据库部分支持不同类别数据的分类(后端能够以此为过滤条件)


## 后端描述

- 采用langgraph + langchain + milvus + mysql + fastapi
- 所有关键数据存储在config.ini中, 此文件能够通过前端专业页面进行动态调整
- 支持各种类型文件的接收
- 支持各种文件的切片,切片方式采用父子块
- 支持通过前端上传的json文件使用ragas进行系统评估
- 支持skill 和 mcp调用和配置能力
- agent能够根据用户输入问题以及向量数据库的描述 判断是否检索向量数据库以及采用什么检索策略
